IoT Backpressure Simulator – có ý nghĩa chính là mô phỏng hệ thống thu thập dữ liệu từ cảm biến với nhiều Node và quản lý overload (backpressure). Nói nôm na là:

1️⃣ Producer → LoadBalancer → Node → Queue → Worker → CSV

Mỗi thành phần có ý nghĩa:

Thành phần	Ý nghĩa / Mục tiêu
Producer	Giả lập cảm biến gửi dữ liệu liên tục. Giúp tạo áp lực (overload) cho hệ thống.
LoadBalancer	Chia đều dữ liệu tới nhiều Node. Giúp demo distributed system và failover nếu 1 node chết.
Node	Nhận request từ LoadBalancer. Chứa queue để lưu tạm dữ liệu chờ xử lý.
Queue	Hàng đợi dữ liệu. Nếu đầy → Node reject request → đây là backpressure.
Worker	Xử lý dữ liệu từ queue. Giả lập chậm để queue tăng → dễ thấy reject khi overload.
CSV / Storage	Lưu dữ liệu đã xử lý. Giúp chứng minh dữ liệu không bị mất.
